03 / ABOUT THE PROJECT

Technology with a purpose.

TruthLens AI is an academic machine-learning project focused on classifying news text into fake and real categories using Natural Language Processing.

The system converts text into numerical features using TF-IDF and applies a trained classification algorithm to generate a prediction.
